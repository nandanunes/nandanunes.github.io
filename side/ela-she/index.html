Ela (She)

Role
Game Design
Occasion
College Project
Year
2014

Ela (She) is a Textual Navigation experience developed using Processing in June 2015 for Computer Graphics Technology class (University of Sao Paulo).

The game

The main objective is to control a camera from the first-person point of view, going through floating phrases and small texts at the screen. After collecting some of the text pieces the game ends showing the collected fragments in order, resulting in a tiny story about this anonymous woman.

The texts were written in a way that in any order the player can comprehend the story, being mainly about a lonely and sad woman dealing with ordinary daily situations.
