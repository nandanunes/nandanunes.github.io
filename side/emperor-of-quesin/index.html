Emperor of Quesin

Game intro.

Role
Game Design, Narrative, UX/UI
Occasion
College Project
Year
2015

Emperor of Quesin is a side-scrolling shooter game where the player controls a tiny cute animal (here, a rabbit) to save Quesin from the claws of a horrible Cat emperor.  The game is a project made during the Interactive Media class at California State University San Bernardino (Fall 2015).

The game

Inspired by 80s setting and cute little forest animals, the game is a side-scrolling shooter where the player needs to control an animal hero to save their city from the claws of an evil cat emperor. The game was made for mobile platforms inspired by games such as Tap Titans and Blitzcrank’s Poro Roundup (both for iOS and Android).
